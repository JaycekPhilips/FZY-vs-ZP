# 对战模式、AI 与球员技能

## 2026-10-08 大力射门与碰撞更新

- 双方在经典和特技模式均可使用大力射门：范志毅默认 L，赵鹏默认小键盘 0。采用原生踢球动作，只在小腿/脚背实际接触身前球时施力；范志毅将真实出脚后的球速提高 20%，不叠加弧线落叶射门。赵鹏沿用掠地瞬击的低平处理和部位、顶牛限制，在原掠地瞬击出球参数上提高 20%。特技模式下赵鹏再额外提高 10% 球速并显示掠地瞬击效果，经典模式没有技能动画和高光。
- 赵鹏头球默认改为右 Shift，普通射门仍为小键盘 Enter。普通射门双击不再发动掠地瞬击。键位设置新增双方“大力射门”，共十四个动作键位，可修改和保存。
- 范志毅普通射门 K 的弧线落叶射门维持同一空间弧线，沿弧线的推进速度降低 10%；在门前按实际速度计算自然下坠。足球与球员肢体使用连续碰撞；每个物理步检测真实碰撞路径，遇到球员或门框时停止曲线施力，真实碰撞后不会继续推球穿透障碍。
- 赵鹏紧急回防保留现有回退速度，通过腿部控制和躯干真实阻尼力矩保持平衡，不直接改旋转或移动肢体。
- 加强磁力脚和强力抢断的地面对抗：真实夹球时保持短步幅并提高推进力；隔着足球顶牛也可使范志毅短暂失衡，约半秒恢复，持续对抗有触发冷却。


## 模型 75% 实验副本

这是独立实验版本。经典、特技及所有对战方式中，两名球员和足球均等比缩小 25%；贴图、肢体、碰撞体和连接关节同步缩小。两侧球门以球场地面为基准降低 20%，门框、球网、碰撞体、进球及出界触发区域同步缩短；门宽和门线位置保持原样，重新发球不会重复缩小。球场、足球开球落点保持原样。球员和足球的质量、重力、跳跃力保持原参数，因此跳跃高度保持原版水平。

普通射门不改变原来的动作速度或自由飞行规律；只在射门动作中真实碰到球时补偿缩短腿臂造成的接触冲量变化。弧线落叶射门的弧线高度降低 10%，保留自然下坠、真实接触和门框目标。模型缩小仅在本副本生效，原版保持正常尺寸。

本副本已同步赵鹏头球下半身镜像修复、地滚球进球判定修复和门后出界处理。运行源文件额外包括 `ExperimentScale.cs`，正式游戏不含测试组件。副本根目录的《实验版说明.txt》列出验证结果。

点击主菜单的“开始”，先选择经典模式或特技模式，再选择双人对战、操控范志毅挑战赵鹏 AI、操控赵鹏挑战范志毅 AI。重新开始保持当前玩法和对战方式；返回主菜单可重新选择。左下角显示当前玩法。

## 玩法

经典模式不启用球员技能、技能动画或足球高光。范志毅后退速度为原版参数的 0.975 倍；赵鹏后退速度为原版参数的 1.5 倍。赵鹏向前速度在上轮 0.75 倍基础上提高 20%，现为原版参数的 0.9 倍；前进施力和速度上限同步调整。这些基础速度调整对所有玩法和对战方式生效。赵鹏前进和后退的摆腿频率仍对齐范志毅未开技能时的普通前进频率。原有的 AI、菜单显示和音量修复仍然保留。

所有模式中，双方初始开球和进球后重置的位置均移到各自门线上。按球门得分触发区域面向球场的一侧定位躯干，整名球员一起平移，并由原生重置动作保存和恢复肢体姿态。足球的中场、左侧、右侧原始下落位置与高度不变。

所有模式中，未判为有效进球的足球一旦整体越过任一侧门线，均判为出界，包括落在球门后方、网外或从球门上方落下的情况。执行原有出界哨声和两秒后重新发球流程，比分不增加；出界球返回场内穿过球门也不能得分。已经判定的正常进球继续执行原有庆祝及重发球流程。

特技模式启用以下十个技能，玩家与 AI 使用相同的触发规则。射门沿用原按键：范志毅无论地面或空中，单击 K 即可准备增强的弧线落叶射门；赵鹏按小键盘 0 执行大力射门并发动掠地瞬击，普通射门双击不再发动。有效指令开启 0.75 秒真实接触窗口，每个射门指令最多成功发动一次，长按不会重复发动。范志毅可在空中按 S（下指令）快速落地。所有技能只调整物理参数与施力，保留原来的球员模型、贴图、动作、肢体关节及球员身体碰撞。

除“空中堡垒”、“紧急回防”、“强力抢断”和范志毅的“伸脚抢截”外，其余六个技能均要求足球位于球员身前或正上/下方；球在身后时不触发，普通踢球、头球、移动与跳跃仍然有效。前后按球员朝向判断：范志毅面向右侧球门，赵鹏面向左侧球门，不因向后移动而反转。“空中堡垒”起跳即可发动；“紧急回防”向后移动即可发动；“强力抢断”要求与身前对手实际身体接触，或双方腿脚真实夹住同一颗贴地足球并由赵鹏向前推进；范志毅的“伸脚抢截”在空中采用半自动触发：身前、球上沿低于站立大腿上沿的低平来球自动发动，身后球按 S 手动发动。这四个技能都不受球的前后位置限制。

| 球员 | 技能 | 触发方式与效果 |
| --- | --- | --- |
| 范志毅 | 旋风盘带 | 地面移动盘带时自动触发，沿用原来的走跑动作，将摆腿频率提高至 1.5 倍，通过脚与球的真实碰撞控球，不施加吸球力。停止盘带、起跳或射门时恢复原动作速度。 |
| 范志毅 | 炮弹式头球 | 身前可及的球触发增强头球，每次头球指令只成功发动一次。保留此前速度降低 5% 的基础，并在其上再降低 10%（合计为最初参数的 85.5%）。经典模式及普通物理头球也在现有基础上降低 10%。 |
| 范志毅 | 弧线落叶射门 | 地面或空中单击 K 均开启 0.75 秒真实接触窗口，可配合任意方向。只有原有小腿碰撞体及独立脚碰撞体的真实接触可发动，包含脚背、脚背与小腿之间的部位；大腿、膝盖、脚底、头部、躯干、手臂不算，也不扩大碰撞体。足球仍须在身前；双方躯干的水平间隔必须至少为两侧门线距离的四分之一，地面或空中顶牛争球时均禁止触发，玩家与 AI 共用这一规则。技能根据对方实际门框位置规划高飘后明显下坠的增强弧线：上升参数 15.75，弧线高度上限 4.2，前进球速参数 12～18，远近射门自动调整弧线。球到达门框前缘或安全门前落点时，弧线辅助立即结束，随后由原生重力和碰撞控制；不会在门前停球等待高度校正。每次单击最多发动一次，显示紫色足球高光。没有位置搬移、禁用碰撞或直接修改比分。赵鹏特技模式的掠地瞬击采用相同的小腿以下接触范围，脚底限制保持原样。 |
| 赵鹏 | 空中堡垒 | 按方向键 ↑ 起跳。在此前已降低 5% 的基础上，再将当前目标跳起高度降低 20%（保留当前高度的 80%）。按高度与起跳速度的平方关系，将当前起跳力乘以 √0.8，最终约为原版起跳力的 1.17690 倍，理论高度为最初空中堡垒的 76%。实际高度仍由重力和接触决定。 |
| 赵鹏 | 强力抢断 | 与身前范志毅的上半身发生实际侧向身体碰撞时自动触发，足球在赵鹏身前或身后都可触发。新增隔球地面对抗：双方均站在地面、双腿真实夹住同一颗贴地足球，且赵鹏向前推进时，即使上半身尚未接触，也能使范志毅短暂失衡；无需射门或新按键。地面直接碰撞的线性冲击再提高 40%、转动冲击提高 35%，隔球冲击采用该力度的 85%；空中原有力度保持不变。双方完整骨架承受大小相等、方向相反的冲量，只短暂减弱范志毅头部和躯干的平衡控制，手臂与双腿保留原控制。新增约两个身位的水平击退：以范志毅站立时的实际身体宽度计算目标距离，模型 75% 版相应缩短；整套骨架通过水平冲量推开并减速，击退后段通过真实力矩辅助恢复平衡。直接碰撞、隔球顶牛与空中碰撞共用这一效果；球门或障碍物会限制实际距离。地面／隔球／空中失衡参数为 0.28／0.26／0.32 秒，随后平滑恢复，单次隔球实测约半秒恢复。赵鹏地面质量暂时提高至 1.45 倍、持续 0.20 秒；空中仍为 1.35 倍、持续 0.16 秒。地面触发冷却至少 1.05 秒，空中至少 0.95 秒，切换状态也尊重上次冷却；贴地短暂离地不会误用空中强冲击。远处对手、仅单人碰球或仅射门指令不会引发隔球失衡。显示跟随赵鹏躯干的绿色冲击箭头与技能名。 |
| 赵鹏 | 掠地瞬击 | 与小键盘 0 的大力射门合并：单次按下后 0.75 秒内，小腿、踝部或脚背实际碰到身前球才发动，部位范围与弧线落叶射门一致，地面和凌空球均可触发；脚底、大腿、膝盖、头部和身体不算，顶牛时不触发。保持高速低平球路，凌空球迅速压低。本轮球速先乘大力射门的 1.2，再乘本技能的 1.1（合计为此前掠地瞬击速度的 1.32 倍），显示金色足球高光及技能动画；对手触球即结束低平辅助。 |

| 赵鹏 | 磁力脚 | 对身前脚边、速度可控的球自动使用原有关节控球；短步控球姿态保留，但生效时前移速度上限与范志毅未使用进攻提速时一致，不再额外降速。真实顶牛时保留原有推动力，仍可接球、带球和射门；身后、空中高球、射门、头球、起跳与暂停时释放控制。 |
| 范志毅 | 伸脚抢截 | 身前近距离、低平飞来的球，且球的上沿低于正常站立时的大腿上沿时，空中自动伸脚快速下落抢截。高度按各版站立模型固定测量，跳起后不扩大。地面、身后、远球、静止球、远离球和陡落球不误触发；身后球仍保留原来的手动下落按键。 |

技能触发时，对应球员周围显示短暂动画和技能名。技能名使用透明背景、彩色文字和细白描边，没有黑色底框。成功打出炮弹式头球、掠地瞬击、弧线落叶射门时，足球分别显示橙红、金黄、紫色高光与拖尾。高光跟随足球的实际渲染位置，不替换足球模型，也不新增声音。

射门技能施力按物理更新频率执行，有速度/加速度上限，不直接搬动球员、足球或肢体。盘带通过原来的动作、肌肉与关节控制实现；强力抢断只在真实身体碰撞或双方腿脚与贴地足球构成真实接触链时施力，不吸球或直接改变球权，不更改模型、肢体长度、碰撞体尺寸或关节连接。进攻提速同步提高原有跑步动画频率，接近球盘带时恢复到旋风盘带自身的 1.5 倍频率，不叠乘动画速度。提高物理解算精度，以维持身体冲撞和高速回防时的原关节连接。暂停、进球重置、退出场景都会恢复动作、质量和平衡参数，清理技能窗口和高光。

主屏幕原有操作说明保留，并按当前键位显示双方头球（默认范志毅 J、赵鹏右 Shift，经典模式也可使用）；不列出特殊技能介绍，只加一句“在特技模式下用赵鹏按大力射门键，有奇效！”。

AI 在特技模式使用相同的真实接触规则：范志毅在任何姿态下第一次射门即可准备增强弧线，赵鹏使用专门的大力射门动作，无需双击。双方 AI 在真实夹球或近身身体顶牛时只通过方向输入对抗，停止普通射门、大力射门和头球；脱离顶牛后恢复正常进攻。持续对抗时按关节负荷略减推进，保持骨架稳定。高空球使用双方实际移动速度、跳跃力、重力及模型比例，预测未来 1.6 秒内的下降拦截点，提前跑位并在可达时起跳；高速掠过或过高的球不会引发无意义射门、头球或起跳。经典模式维持原玩法。暂停、足球转到身后或重置均清除射门等待状态。

AI 每帧根据球的速度和重力预判截球位置，从己方球门一侧靠近，并按球的高度、距离和动作冷却决定跳跃、踢球、头球。它使用游戏原有的移动和动画逻辑，没有直接移动足球或修改比分。

赵鹏 AI 对范志毅正在飞行的弧线落叶射门使用专门的防守预判：根据技能实际的上升、弯曲和急坠路径寻找门线前能够到达的拦截点，提前移动占位；需要争高球时，按现有跳跃参数预估接球高度和时机。球即将到达头部时优先执行头球，避免待执行的大力射门压过头球；低球则及时出脚。预测只读取状态并模拟未来球路，真实拦截由原有移动、起跳、头球、射门及身体碰撞完成。

近身争球时，AI 会识别对手也在球旁，持续向进攻方向施压。踢球和头球分别按脚、头的实际位置判断；空中夹球会更积极地跳起争顶。AI 双方的额外推力保持一致。

开球或球重置后，双方 AI 从门线主动向足球落点进攻；未受干扰的开球接近阶段只前进或停步，按自身速度提前减速，避免冲过落点。跳跃要求预测后的水平位置接近足球，并且球即将进入能够争到的高度，或正在近身空中争抢；远处落球不会引发无意义起跳。足球被击走、双方开始争球后恢复正常攻防，球到身后时仍可回防；近身争球之外不使用额外推力。

选择模式后，主菜单和选择层会关闭，再进入对战场景。球碰撞音量也会遵守游戏设置中的“音效”滑块；设为 0 时球声静音。

- `GameAIMod.cs`：模式菜单与双方 AI 的源码。
- `ControlBindings.cs`：双方键位映射、设置界面与 INI 配置保存。
- `ZhaoHeader.cs`：赵鹏真实甩头动作的独立采样与头部、躯干角度镜像；保留腿脚朝向。
- `build/ControlsTests.cs`：隔离测试中的默认键位、改键、保存恢复、普通头球动作及真实碰撞测试。
- `build/ZhaoVolleyTests.cs`：隔离测试中的真实弧线射门、赵鹏防守与开球回归测试；另与修改前 AI 使用相同射门位置对比。
- `PlayerSkills.cs`：十个技能、球员动画、足球高光及玩法标识。
- `PlayerMovement.cs`：基础后退提速、赵鹏摆腿频率、移动技能速度参数。
- `MagneticFoot.cs`：赵鹏特技模式的前脚控球、停球与支撑腿模组，只操作原有腿部动作和球员步幅。
- `PatchGame.cs`：将菜单和输入调用接入原游戏程序集的源码。
- `Assembly-CSharp.original.dll`：修改前的原版程序集备份。
- `Assembly-CSharp.patched.dll`：已安装到 `FanZhiYi_Data/Managed` 的修改版副本。

运行时还需要 `FanZhiYi_Data/Managed/GameAIMod.dll`。要恢复原版，把 `Assembly-CSharp.original.dll` 复制回 `FanZhiYi_Data/Managed/Assembly-CSharp.dll`，并移除同目录的 `GameAIMod.dll`。

编译源码可使用 Windows .NET Framework C# 编译器。`PatchGame.cs` 依赖 NuGet 的 Mono.Cecil 0.11.6；游戏运行不需要 Mono.Cecil。

正式版只编译 GameAIMod.cs、PlayerSkills.cs、PlayerMovement.cs、ControlBindings.cs、ZhaoHeader.cs、PowerShot.cs、ExperimentScale.cs；没有测试组件或自动操作入口。

用户要求：本次及以后的修改都要测试后更新。除编译外，应在隔离的游戏副本中运行与修改相关的实际场景测试，检查正常玩法和修复后的行为；测试代码不能编入正式游戏。本次门后出界测试源码为 `build/BehindGoalTests.cs`，覆盖经典和特技模式、左右两侧出界、门后地面及空中球、反弹返回球门、正常进球、重新发球和暂停恢复。



地滚球进球判定：球门开口的下边界采用实际球场地面高度，而非原生触发矩形的下边缘。足球从场内向球门滚入、且完全位于横梁下方时可以得分；补充连续跨线检查，避免小球或快速球漏过原生触发区域。已经有效进球的足球不会再被出界触发器截断；比分只增加一次。门后出生、横梁上方出界和出界后反弹回门仍判为出界。


上角进球修复：采用球门真实横梁下缘作为上边界，持续跟踪首次高处接触触发区域后下落入网的过程，并补充跨越门线时的高度插值；球从场内贴近上角进入真实门框会计分。越过真实横梁、门后出生、出界反弹仍不能得分，地滚球与正常进球判定保留。每次修改测试安装后同步推送源码和两版完整游戏包到 GitHub。

## 2026-10-09 强力抢断击退更新

## 2026-10-09 回防与球速更新

32 位原版和模型 75% 实验版统一更新（本次按用户要求跳过 64 位版）：磁力脚生效时的赵鹏前移速度与范志毅未使用进攻提速时一致，双方主动头球球速在原有基础上降低 10%，范志毅伸脚抢截自动范围扩展至站立大腿上沿以下。强力抢断的约两个身位击退及脚—球—脚顶牛触发保留。

新增自动回防与原来的手动加速同时存在，自动回防遵循上表的球高分支及速度上限，使用真实起跳、碰撞与关节。头球解围根据横梁高度选择球路，空间不足时先将球转回场内；向后下腰姿态只用于自动回防，普通头球动作保持。自动过程和结束后的短暂物理恢复帮助赵鹏维持平衡，不冻结模型或移动足球。
