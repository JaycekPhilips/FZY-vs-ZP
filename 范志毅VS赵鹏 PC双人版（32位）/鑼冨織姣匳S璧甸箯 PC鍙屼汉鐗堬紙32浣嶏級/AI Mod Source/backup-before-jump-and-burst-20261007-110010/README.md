# 对战模式、AI 与球员技能

点击主菜单的“开始”，先选择经典模式或特技模式，再选择双人对战、操控范志毅挑战赵鹏 AI、操控赵鹏挑战范志毅 AI。重新开始保持当前玩法和对战方式；返回主菜单可重新选择。左下角显示当前玩法。

## 玩法

经典模式保留原来的动作参数，不启用球员技能、技能动画或足球高光。原有的 AI、菜单显示和音量修复仍然保留。

特技模式启用以下六个技能，玩家与 AI 使用相同的触发规则，不增加新按键。所有技能只调整物理参数与施力，保留原来的球员模型、贴图、动作、肢体关节及球员身体碰撞。

| 球员 | 技能 | 触发方式与效果 |
| --- | --- | --- |
| 范志毅 | 旋风盘带 | 站在地面并靠近低球时自动触发。用有上限的水平控球力把球留在脚前；射门后的短时间内不拖慢射出的球。 |
| 范志毅 | 炮弹式头球 | 按 J 执行头球，球进入头部接触范围后施加一次强力向前冲量。短暂的足球争顶优先窗口避免立即被对方夹回；不关闭球员身体之间的碰撞。 |
| 范志毅 | 弧线落叶射门 | 按 K 单独射门或配合任意方向指令，每次射门都开启/刷新 0.75 秒的接触窗口。期间任一只脚实际接触未落地的球即可触发，包括低空球、脚尖和脚侧接触，球员无需跳起。仅靠近身体、头部触球或没有射门指令时不会触发。对方触球、落地或重置会结束弧线辅助。 |
| 赵鹏 | 空中堡垒 | 按方向键 ↑ 起跳。起跳力为原来的 1.35 倍，实际高度仍由重力和接触决定。 |
| 赵鹏 | 伸脚抢截 | 靠近地面球时自动触发，无需射门指令。抢截范围扩大到身前 2.6 个场景单位，用受限冲量收球，不伸长腿或移动球的位置；触发间隔 0.6 秒，射门后短暂不回拉自己的球。 |
| 赵鹏 | 掠地瞬击 | 按小键盘 Enter，球在脚前射门范围内且接近地面时，打出更快的低平球。较远的球先按抢截规则处理。 |

技能触发时，对应球员周围显示短暂动画和技能名。技能名使用透明背景、彩色文字和细白描边，没有黑色底框。成功打出炮弹式头球、掠地瞬击、弧线落叶射门时，足球分别显示橙红、金黄、紫色高光与拖尾。高光跟随足球的实际渲染位置，不替换足球模型，也不新增声音。

技能施力按物理更新频率执行，有速度/加速度上限，不直接搬动球员、足球或肢体。暂停、进球重置、退出场景都会清理技能窗口、高光和临时足球碰撞参数。

AI 每帧根据球的速度和重力预判截球位置，从己方球门一侧靠近，并按球的高度、距离和动作冷却决定跳跃、踢球、头球。它使用游戏原有的移动和动画逻辑，没有直接移动足球或修改比分。

近身争球时，AI 会识别对手也在球旁，持续向进攻方向施压。踢球和头球分别按脚、头的实际位置判断；空中夹球会更积极地跳起争顶。AI 双方的额外推力保持一致。

开球或球重置后，AI 会先在本方侧接应高空落球，并提前刹车。球第一次落到较低位置、被击向一侧，或对手进入近身争球时，AI 再向球靠近；近身争球之外不使用额外推力。

选择模式后，主菜单和选择层会关闭，再进入对战场景。球碰撞音量也会遵守游戏设置中的“音效”滑块；设为 0 时球声静音。

## 文件

- `GameAIMod.cs`：模式菜单与双方 AI 的源码。
- `PlayerSkills.cs`：六个技能、球员动画、足球高光及玩法标识。
- `PatchGame.cs`：将菜单和输入调用接入原游戏程序集的源码。
- `Assembly-CSharp.original.dll`：修改前的原版程序集备份。
- `Assembly-CSharp.patched.dll`：已安装到 `FanZhiYi_Data/Managed` 的修改版副本。

运行时还需要 `FanZhiYi_Data/Managed/GameAIMod.dll`。要恢复原版，把 `Assembly-CSharp.original.dll` 复制回 `FanZhiYi_Data/Managed/Assembly-CSharp.dll`，并移除同目录的 `GameAIMod.dll`。

编译源码可使用 Windows .NET Framework C# 编译器。`PatchGame.cs` 依赖 NuGet 的 Mono.Cecil 0.11.6；游戏运行不需要 Mono.Cecil。

正式版只编译 `GameAIMod.cs` 和 `PlayerSkills.cs`，没有自动测试、冻结球员或自动操作逻辑。修改前版本保存在 `backup-before-skills`，可用于回退至没有技能系统的 AI 版本。
